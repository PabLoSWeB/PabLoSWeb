## 🏁 Largada

Trabalhei como operador de processo industrial numa fábrica da Stellantis, em Betim. Foi lá que percebi que queria trabalhar com tecnologia, e saí por decisão própria para me dedicar aos estudos.

Hoje faço Análise e Desenvolvimento de Sistemas na UNA (conclusão prevista: meados de 2028) e aprendo por conta própria: Java e Spring Boot no backend, JavaScript e front-end agora. Construí duas APIs REST do zero, com 22 endpoints no total, e resolvi 10 desafios de CTF (criptografia, exploração web e perícia forense).

Acompanho de perto a evolução da IA e uso como apoio para estudar e depurar. O código dos meus projetos é escrito por mim. A ideia é chegar em automações e integrações com IA.

### 🔧 No momento

- 📚 Estudando JavaScript e front-end
- 🎯 Procurando estágio em desenvolvimento
- 🤖 Explorando IA aplicada a automações
